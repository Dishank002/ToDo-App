# 📝 To-Do App

A simple and elegant web-based To-Do List application built with **Python Flask** and **SQLite**. Easily add, edit, mark complete, or delete tasks — all in a user-friendly interface.

---

## 🔧 Tech Stack

- **Backend**: Python (Flask)
- **Database**: SQLite
- **Frontend**: HTML, CSS, Jinja2 templates
- **IDE**: Visual Studio Code

---

## 🚀 Features

- ➕ Add new tasks  
- ✏️ Edit task titles directly on the same page  
- ✅ Mark tasks as complete/incomplete with a checkbox  
- ❌ Delete tasks  
- 🎨 Simple and responsive UI with helpful labels like *"Click on title to edit"*
